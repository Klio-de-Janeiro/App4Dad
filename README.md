# Михеев · App4Dad

Ручное копирование новых и изменённых файлов с ПК на флешку. Приложение Windows и Android-пульт для управления тем же компьютером по локальной сети.

## Скачать готовые приложения

[Релиз 1.0.0 — установщик Windows, переносимый ZIP и Android APK](https://github.com/Klio-de-Janeiro/App4Dad/releases/tag/v1.0.0).

- **App4Dad-1.0.0.exe** — полноценный установщик Windows со встроенной Java. Создаёт ярлыки в меню «Пуск» и на рабочем столе; установка для текущего пользователя.
- **App4Dad-Windows-x64.zip** — переносимая версия без установки. Распакуйте всю папку и запустите находящийся в ней `App4Dad.exe`.
- **App4Dad-Android.apk** — Android-пульт для управления копированием на компьютере.

## Быстрый запуск Windows

1. Распакуйте **весь** `App4Dad-Windows-x64.zip` в удобное место.
2. Запустите `App4Dad/App4Dad.exe`. Установка Java не нужна. Windows 10/11, x64.
3. Проверьте папки: откуда `S:\Михеев`, куда `E:\Михеев`. Буква флешки может отличаться — её можно изменить.
4. Выберите даты изменения: по умолчанию вчера и сегодня. Даты включены полностью, по часовому поясу ПК. Есть «Сегодня» и «Все даты».
5. Нажмите **«Сравнить папки»**. На этом шаге файлы не записываются.
6. Проверьте список; при необходимости снимите галочки. Нажмите **«Скопировать выбранное»** и подтвердите.

Для корректного отключения флешки дождитесь завершения операции и используйте безопасное извлечение Windows.

## Android — пульт для Windows

Android **8.0+**. Это управление копированием на ПК, поэтому флешка подключается к компьютеру. Приложение Windows должно быть открыто. Доступа к буквам дисков непосредственно с телефона не требуется.

1. Установите `App4Dad-Android.apk` на телефон, разрешив установку этого APK, если Android попросит.
2. Подключите телефон и ПК к одной локальной сети (обычно к одному Wi-Fi-роутеру).
3. В Windows нажмите **«Подключить Android-пульт»**. Перенесите указанный адрес `IP:48123` и код сопряжения в Android. Если адресов несколько, используйте адрес вашего Wi-Fi/Ethernet.
4. При запросе брандмауэра Windows разрешите приложению входящие подключения **для частной сети**. Приложение само правила брандмауэра не меняет. Не открывайте порт на роутере.
5. На телефоне нажмите «Подключиться», выберите даты, сравните папки, проверьте список и подтвердите копирование.
6. Завершив работу, в настройках пульта Windows нажмите «Отключить пульт». При следующем включении код будет новым.

Папки источника и назначения задаются на ПК; телефон не может менять их. Пульт копирует все доступные для копирования файлы в подтверждённом списке. Выбор отдельных файлов галочками доступен в Windows. Списки в Android показываются страницами по 100 строк. Во время операции статус обновляется; после потери связи операция на ПК может продолжаться — подключитесь заново и проверьте состояние.

## Что именно копируется

- По всем вложенным папкам отбираются **файлы источника** с датой изменения в выбранном периоде. Отсутствующие файлы вне периода тоже пропускаются. «Все даты» предназначено для первого полного копирования.
- Отсутствующий файл — «Новый». При различающемся содержимом — «Изменён». Сравнение по SHA-256 обнаруживает изменения даже при одинаковом размере и времени.
- Совпадающее содержимое не копируется, даже если даты различаются. Если копия на флешке отличается и новее источника более чем на 2 секунды, это конфликт, который не перезаписывается. Допуск учитывает точность времени FAT.
- Файлы, имеющиеся только на флешке, сохраняются. Удалений и автоматического запуска по расписанию нет.
- Создаются необходимые подпапки. Пустые папки отдельно не копируются. Символические ссылки, junction-перенаправления, специальные файлы и ошибки доступа пропускаются с пояснением.
- После сравнения источник и старая копия проверяются повторно. Изменившийся файл требует нового сравнения.
- Запись идёт во временный файл рядом с назначением, проверяется SHA-256, затем выполняется замена. Если файловая система не поддерживает атомарную замену, старый файл остаётся и выводится ошибка. Файловые блокировки и внезапное отключение устройства могут приводить к ошибкам; завершённые файлы не откатываются.
- Кнопка «Остановить» прерывает работу между блоками данных; ранее скопированные файлы остаются. При аварийном завершении процесса может остаться файл `.app4dad-*.part`.
- Сохраняется дата изменения файла; права NTFS, альтернативные потоки и полная история версий не переносятся. Приложение не заменяет версионный архив.

## Сеть и сопряжение

Сервер выключен до нажатия кнопки на ПК. Он принимает только команды состояния, сравнения, подтверждённого копирования и остановки. Код содержит 256 случайных бит, хранится только в памяти и меняется при отключении пульта. Android сохраняет только адрес ПК.

Транспорт HTTP, но каждое сообщение защищено **AES-256-GCM** с уникальным случайным nonce. Код, пути и списки файлов не передаются открытым текстом. Ответ привязан к ID запроса; сервер отклоняет повторы и запросы старше двух минут. Часы телефона и ПК должны быть синхронизированы. После 30 неверных зашифрованных запросов за минуту сервер временно отклоняет подключения. Сопряжённый телефон имеет право запускать копирование в выбранных на ПК папках — не передавайте код посторонним.

## Сборка и проверки

Зависимости: **JDK 17**, **PowerShell 7**, Android SDK Platform 35 и Build Tools 35.0.0. Сторонних библиотек, Gradle и сетевых загрузок при сборке нет.

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-17'
$env:ANDROID_HOME = 'C:\path\to\Android\Sdk'
./scripts/build.ps1
```

Скрипт сначала компилирует и запускает функциональные тесты ядра, шифрования и реального сетевого протокола. Затем собирает Windows JAR, переносимую Windows-папку с Java runtime, ZIP и подписанный Android APK. Параметры `-TestOnly`, `-SkipAndroid` и `-SkipPackage` позволяют выполнять части сборки. Результаты — в `dist/`.

APK подписывается локальным **ключом разработки** `.local/android-dev.p12` (пароль `android`). Это APK для личного использования, не публикация в Google Play. Чтобы будущие APK устанавливались поверх предыдущей версии, сохраните этот локальный ключ; он исключён из Git. CI создаёт отдельный временный ключ: его APK может потребовать удаления ранее установленной версии.

GitHub Actions повторяет тесты и сборку и сохраняет ZIP/APK как артефакты. Сборка не обращается к реальным папкам `S:`/`E:`: тесты работают исключительно во временных каталогах.

Для дополнительной сборки установщика `.exe` потребуется WiX Toolset 3.14. После основной сборки выполните `./scripts/build-installer.ps1 -WixRoot 'C:\path\to\wix3'`. Установщик использует готовую папку `dist/App4Dad` и включает среду Java.

## Устройство проекта

- `core/` — сравнение, проверка путей, копирование и проверка целостности.
- `shared/` — общий защищённый протокол Windows/Android.
- `windows/` — Swing-интерфейс, координатор и сетевой сервер.
- `android/` — нативное Java-приложение без сторонних зависимостей.
- `tests/` — функциональные и интеграционные проверки.
- `scripts/` — воспроизводимая сборка обеих платформ.

Реальные диски пользователя и физический Android-телефон требуют отдельной проверки на его оборудовании.
